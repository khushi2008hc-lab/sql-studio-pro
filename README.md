## ✨ Features

- **⚡ In-Memory Relational Engine:** Executes `SELECT`, multi-table `JOIN`, `WHERE`, and `ORDER BY` operations with microsecond execution telemetry.
- **🗺️ Interactive ERD Diagram:** Visualizes database schemas, foreign keys, and primary keys with interactive cards.
- **🔍 Query Execution Plan (EXPLAIN):** Inspects parsing, indexing cost units, and in-memory join materialization.
- **📁 Multi-Database Schemas:** Preloaded with E-Commerce, University System, and Cloud Streaming databases.
- **📊 CSV Data Export:** Instant one-click CSV table export for analytical reporting.
